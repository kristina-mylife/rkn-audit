# RKN-Audit — аудит приложения на соответствие 152-ФЗ
AI-powered personal data compliance audit for Russian software projects.

**RKN Audit** — бесплатная инструкция для ИИ-агентов, предназначенная для предварительного технического аудита приложений на соответствие требованиям российского законодательства о персональных данных.

## Для кого

- Вайб-кодеры и независимые разработчики.
- Стартапы и владельцы цифровых продуктов.
- Архитекторы и технические специалисты.
- Все, кто разрабатывает приложения с использованием ИИ.

## Что проверяем

- Сбор, обработку и хранение персональных данных.
- Локализацию персональных данных.
- Передачу данных сторонним сервисам.
- Использование внешних API и ИИ-сервисов.
- Согласия на обработку персональных данных.
- Потенциальные риски несоответствия требованиям законодательства.

## Как использовать

1. Скачайте Markdown-файл из репозитория.
2. Передайте его своему ИИ-агенту: Cursor, Claude Code, Codex или другому агенту с доступом к исходному коду проекта.
3. Попросите провести аудит проекта согласно инструкции.
4. Изучите полученный отчёт и рекомендации.

Отчёт формируется на русском языке.
