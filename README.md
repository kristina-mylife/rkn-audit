# RKN-Audit — аудит приложения на соответствие 152-ФЗ
AI-powered personal data compliance audit for Russian software projects.

**RKN Audit** — бесплатный набор материалов для ИИ-агентов, предназначенный для предварительного технического аудита приложений на соответствие требованиям российского законодательства о персональных данных и подготовки сведений для уведомления Роскомнадзора.

## Состав репозитория

- [`RKN_AGENT_CHECKLIST.md`](RKN_AGENT_CHECKLIST.md) — инструкция для ИИ-агента по предварительному техническому аудиту обработки персональных данных, локализации, согласий, подрядчиков, сайта, мер защиты и рисков ответственности.
- [`RKN_OPERATOR_QUESTIONNAIRE.md`](RKN_OPERATOR_QUESTIONNAIRE.md) — анкета-черновик для сбора сведений об операторе, целях обработки и подготовки данных для уведомления Роскомнадзора.

## Для кого

- Вайб-кодеры и независимые разработчики.
- Стартапы и владельцы цифровых продуктов.
- Архитекторы и технические специалисты.
- Все, кто разрабатывает приложения с использованием ИИ.

## Что проверяем

- Сбор, обработку и хранение персональных данных.
- Локализацию персональных данных.
- Передачу данных сторонним сервисам.
- Использование внешних API и ИИ-сервисов.
- Согласия на обработку персональных данных.
- Потенциальные риски несоответствия требованиям законодательства.

## Как использовать

1. Скачайте файлы [`RKN_AGENT_CHECKLIST.md`](RKN_AGENT_CHECKLIST.md) и [`RKN_OPERATOR_QUESTIONNAIRE.md`](RKN_OPERATOR_QUESTIONNAIRE.md) из репозитория.
2. Передайте ИИ-агенту (Cursor, Claude Code, Codex или другому агенту с доступом к исходному коду проекта) `RKN_AGENT_CHECKLIST.md` для технического аудита проекта.
3. Используйте `RKN_OPERATOR_QUESTIONNAIRE.md`, чтобы собрать сведения об операторе и подготовить данные для уведомления Роскомнадзора.
4. Изучите полученный отчёт, рекомендации и пункты со статусом «Не проверено» — часть данных (внешние сервисы, организационные меры, юридические основания) требует проверки за пределами исходного кода.

Отчёт формируется на русском языке.
